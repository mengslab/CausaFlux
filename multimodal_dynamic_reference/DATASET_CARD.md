# CausaFlux v1.7.0 multimodal dynamic benchmark dataset card

This bundled dataset is a deterministic **synthetic software fixture** containing 180 longitudinal trajectories, 36 perturbation histories, 15 donors, and 3 cohorts.

Modalities: rna, imaging, reporter, phosphoprotein, metabolome, lipidome.

Primary split: complete perturbation-history holdout. Donor overlap is intentional and is not described as donor holdout. Synthetic observations are not biological evidence.
