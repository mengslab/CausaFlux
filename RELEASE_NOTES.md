# CausaFlux v2.0.0 release notes

CausaFlux v2.0.0 introduces the evidence-governed prospective-validation release standard.

Major additions:

- hard real-evidence gate for the phrase “Prospectively Validated Virtual Cell”;
- claim-linked evidence ledger with stable claim IDs;
- actual longitudinal perturbation table → dynamic benchmark adapter;
- public longitudinal perturbation registry for GSE8057, GSE70138 and GSE101406;
- direct real held-out-history model benchmark command;
- distribution-shift uncertainty calibration gate;
- explicit negative-result and failed-assay evidence classes;
- ≥2 real prospective-cycle requirement;
- independent external-lab/cohort replication requirement;
- v2 Streamlit release-status interface;
- publication-grade release evidence figures and graphical abstract;
- strict `--require-prospectively-validated` validator.

The bundled reference data establish software integrity only. No synthetic result is eligible to satisfy the v2 biological validation claim.
