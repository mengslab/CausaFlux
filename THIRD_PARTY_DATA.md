# Third-party data and licenses

The MIT license in this repository applies only to CausaFlux source code and original documentation. It does not relicense third-party biomedical data.

CausaFlux v1.4.0 contains accession manifests and two small, unchanged, public SEA-AD metadata snapshots used to verify the real-data reporting workflow. All other assay matrices, images, clinical records, perturbation files, and neurophysiology assets remain at their authoritative repositories.

Before downloading or using a source, users must review the corresponding record in:

- `benchmarks/licenses/data_license_matrix.csv`
- `benchmarks/manifests/*.yaml`
- `realdata_reference/reports/licenses.html`

Controlled-access approval, repository authentication, publication acknowledgement, and data-use restrictions remain the user's responsibility. CausaFlux adapters never bypass those controls.
