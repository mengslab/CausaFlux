Architecture

Time-varying typed tissue graphs are coupled to continuous state-rate models. A learned communication gate weights neighbor messages. Regulatory and organelle graphs remain explicit within-cell graph layers. A Nicheformer file adapter accepts externally generated embeddings without redistributing checkpoints.

Scientific boundary

The bundled benchmark demonstrates software behavior and a synthetic predictive advantage of neighborhood context. It does not establish biological interference, a causal ligand–receptor mechanism, tissue prognosis, or clinical guidance.
