# CausaFlux v1.8.0 prospective-loop reference

This directory is the deterministic synthetic software-validation reference for the v1.8.0 Prospective Experimental Loop.

## Required sequence

- Cycle 1: model frozen, predictions preregistered, experiment executed, QC/outcome locked, evaluation completed.
- Cycle 2: posterior-updated model frozen, new recommendation preregistered, experiment executed and evaluated.
- Cycle 3: orthogonal independent confirmation/falsification experiment(s) preregistered and evaluated.

## Gate

PASS on outcome discovery, experiment efficiency, and recovery-trajectory identification relative to the prespecified fixed-order non-AI strategy. Uncertainty reduction is reported and did not exceed the prespecified improvement margin.

## Evidence boundary

Synthetic software validation only. No real prospective biological claim is authorized by this reference directory.
