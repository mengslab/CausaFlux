# Packaged demonstrations

| Demo | Command | Purpose |
|---|---|---|
| Dynamic model benchmark | `sh demos/dynamic_model_benchmark/run.sh` | Static-versus-dynamic held-out perturbation-history benchmark |
| Cancer quickstart | `sh demos/cancer_quickstart/run.sh` | Reduced-size end-to-end cancer disease-evolution workflow |
| Neurobiology quickstart | `sh demos/neurobiology_quickstart/run.sh` | Neural–glial trajectory and functional integration workflow |
| Integrated reference | `sh demos/integrated_reference/run.sh` | Complete nine-stage cross-domain platform |

Use `causaflux demo-list` to inspect the same registry from the CLI. Synthetic demos are explicitly labeled. The real-data registry and biological-validation demos use public metadata under their recorded access and evidence constraints.
