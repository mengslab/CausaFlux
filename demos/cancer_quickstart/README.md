# Cancer quickstart

This synthetic, reduced-size configuration exercises the complete cancer disease-evolution workflow: multimodal fusion, donor-aware baselines, spatial tumor–immune–stromal graphs, causal effects, counterfactual therapeutics, early-warning biomarkers, and closed-loop experiment recommendations.

```bash
sh demos/cancer_quickstart/run.sh
```

The run also generates a compact neurobiology validation cohort because the v1.0 platform report verifies both supported domains. Outputs are synthetic and are not biological findings.
