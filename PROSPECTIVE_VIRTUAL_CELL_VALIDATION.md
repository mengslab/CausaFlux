# CausaFlux v1.9.0 — Prospective Virtual-Cell Validation

A prospectively validated virtual cell requires more than retrospective fit or a successful synthetic simulation.

## Software integrated gate

The v1.9 software gate requires successful retained validation of:

1. dynamic state forecasting;
2. multimodal state inference;
3. intervention generalization;
4. spatiotemporal context;
5. foundation transfer;
6. prospectively locked Cycle 1→2→3 logic;
7. independent Cycle 3 confirmation/falsification;
8. accession-pinned real-world data governance;
9. real-world observational replication.

## Real prospective gate

The stronger biological label additionally requires:

1. real perturbational validation; and
2. three real prospectively locked experimental cycles, with independent Cycle 3 confirmation or falsification.

Until both conditions pass, `prospectively_validated_virtual_cell` remains `false`.

## Why the distinction matters

The v1.9 bundled reference combines synthetic software validation with genuine real-world observational replication. Those are complementary forms of evidence, but neither should be represented as a completed real prospective intervention study.
